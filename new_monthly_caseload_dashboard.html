Important sharing and data note

This standalone HTML version stores data in the browser's local storage. It is suitable for a prototype or single-device use, but figures entered by one person will not automatically appear for other people. To make a genuinely shared live dashboard, connect it to a shared data source/database and host the page (for example, through an approved organisational platform). Do not enter identifiable or confidential case information into a publicly hosted page.
